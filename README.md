# BibliotecaPython

Pesquisa sobre bibliotecas Python para conexão com bancos de dados.

## Sobre a atividade

Este repositório reúne a pesquisa realizada sobre as principais bibliotecas Python utilizadas para conectar aplicações a bancos de dados, apresentando suas características, formas de uso e diferenças.
